# Hierarchy, typography, spacing, and layout

- Make the primary message, supporting explanation, and primary action legible in that order. Use contrast in scale, weight, placement, and whitespace instead of decorating every element.
- Start from the product's existing typefaces and type scale. Protect readable line lengths, deliberate wrapping, clear heading levels, and comfortable text leading.
- Use the existing spacing system or infer a small repeatable rhythm from the page. Align related edges, keep grouping consistent, and avoid arbitrary one-off offsets.
- Build compositions on a resilient grid. Check how focal content and supporting visuals balance at wide, medium, and narrow widths.
- Do not solve weak hierarchy with excessive gradients, glow, glass panels, rounded cards, floating pills, or oversized display type.
